# **📚 Student Resource Sharing Platform**

A web application that allows students to upload, share, and access previous year question papers in one place.

# **🚀 Features**

- 📤 Upload previous year papers and study materials
  
- 📥 Download resources(easy access for all students)
  
- 🔍 Search and filter by subject/year
  
- 🔐 Secure authentication (JWT-based)
  
- 📱 Responsive and user-friendly interface

# **🛠️ Tech Stack**

- Frontend: React
  
- Backend: Node.js, Express.js
  
- Database: MongoDB
  
- Authentication: JWT
  
- Uploads: Multer

# **📂 Project Setup**

   ```
   git clone https://github.com/pratishthanandwal/resource-sharing-platform.git
   cd frontend
   npm install
   cd backend 
   npm install
   ```

   ```
   # Run backend
   npm start

   # Run frontend
   cd backend
   npm start
   ```

#  **🔑 Environment Variables**

    ```
    MONGO_URI=your_mongodb_connection
    JWT_SECRET=your_secret_key
    ```
